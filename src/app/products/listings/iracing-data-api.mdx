`iracing-data-api` is a collection of packages oriented around consumption of the iRacing `/data` API.

It provides OAuth and API clients, schemas, helpers and examples for interacting with the iRacing `/data` API
in TypeScript and Rust.

## Packages

### Rust
  - `iracing-data-api-client`: An OpenAPI-generator `/data` API client.

### TypeScript
  - `@iracing-data/oauth-schema`: A zod schema for the iRacing OAuth API.
  - `@iracing-data/oauth-client`: An OAuth client for iRacing.
  - `@iracing-data/api-schema`: A zod schema for the iRacing `/data` API.
  - `@iracing-data/api-client-fetch`: An OpenAPI-generator `fetch` client for the `/data` API.
  - `@iracing-data/api-client-axios`: An OpenAPI-generator `axios` client for the `/data` API.
